# Chutes-and-Ladders
Chutes and Ladders game written in C++.
This was a final project for my ECGR 2103 - Computer Utilization in C++ class.

The game consists of players rolling dice during turns in order to reach the end of the board.
Along the way, there will be chutes that slide you down the board and ladders, which climb you along the board.
It can come with questions along the way, allowing for a chance to roll again.
The first one to reach the end of the board wins.
